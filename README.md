A two-line robot confession for the [make.fun bounty "The Robot Apology"](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59): one sentence owning a specific mistake, one naming the lesson and the fix.

`main.py` is deterministic — no network, no randomness — and writes the entry to `/output/entry.txt`.
